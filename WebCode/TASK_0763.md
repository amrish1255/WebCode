# Backend Development Task

## Task ID
TASK-DBCONNECTION

## Agent
Backend Developer

## Project Scope
DATABASE_ONLY

## Required Skills
- project.md
- DB/SKILL.md
- Security/Security.md

## Requirement
Optimize and refactor `DapperContext` to ensure consistent database connections and error handling.

## Business Problem
- Duplicate open/close logic in DB connections.
- Inconsistent error logging.
- No retry logic for transient SQL errors.

## Objective
- Simplify connection handling.
- Improve logging with stored procedure context.
- Add resiliency for transient failures.

## Acceptance Criteria
- All stored procedure methods use a unified helper.
- Connections are disposed correctly.
- Logging includes stack trace and stored procedure name.
- Retry logic implemented for transient failures.

## Constraints
- Preserve layered architecture.
- Do not modify unrelated functionality.
- Do not bypass security.

## Expected Areas
Infrastructure:
- `web.Repository/DapperContext.cs`

Configuration:
- `WebCode/appsettings.json` (connection strings)

## Deployment
- Backend only (Infrastructure layer)

## Rollback
- Restore previous `DapperContext` implementation if issues occur.

## Special Instructions
- Test with multiple stored procedures.
- Validate connection resiliency with simulated SQL errors.
